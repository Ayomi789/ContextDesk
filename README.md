# ContextDesk

An AI-powered CRM ticketing platform that combines customer support and CRM into one modern workspace.

## Tech Stack

- React
- Vite
- TypeScript
- Express
- PostgreSQL
- Prisma
- Tailwind CSS
- NVIDIA (GPT-OSS 20B, for AI reply drafts)

## Project Structure

apps/
- api — Express + Prisma backend

packages/
- shared-types — contracts shared with frontends

The maintained React frontend lives outside this repo (see docs/SETUP.md).
